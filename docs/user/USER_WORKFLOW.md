# SimCo Planner — User Workflow

Welcome! This tool helps you plan your company and see results instantly.

You only need to work in the Excel spreadsheet.

---

## ✅ Quick Start

### 1. Enter your plan
Fill in the tables on the **Inputs** sheet:
- What you want to produce
- How you want to sell it
- Any other settings

---

### 2. Run the calculation

#### Option A — Preferred (Macros Enabled)

Click:

[ Calculate ]

---

#### Option B — If the button does not work (Macros Disabled)

1. Double-click:
   run_engine.exe

2. Return to Excel and click:
   Data → Refresh All

---

### 3. View results

Check the **Outputs** sheet for:
- Production results
- Sales breakdown
- Key diagnostics

---

## ⚙️ What the System Does

When you run the calculation, the system:

1. Reads your inputs from the spreadsheet  
2. Runs the calculation engine  
3. Updates your results  

You do not need to manage files or run anything manually.

---

## ⚠️ If the Calculate Button Doesn’t Work

Excel may disable macros for security.

If that happens, use the manual steps below.

---

## ✅ Manual Run (No Macros)

1. Make your changes in Excel  
2. Run:
   run_engine.exe  
3. Back in Excel, click:
   Data → Refresh All  

---

## 🧠 How It Works (Simple Explanation)

You only interact with the spreadsheet.

Behind the scenes:

Your inputs  
→ Engine runs calculations  
→ Results are updated  

---

## 📌 Tips

- Use dropdowns where available  
- Fill in all required fields  
- Click **Calculate** after making changes  

---

## ❗ Troubleshooting

### Results didn’t update?
- Click **Calculate**
- Or run `run_engine.exe` and then refresh Excel

---

### Something looks wrong?
- Check your inputs
- Verify priorities and values are correct

---
